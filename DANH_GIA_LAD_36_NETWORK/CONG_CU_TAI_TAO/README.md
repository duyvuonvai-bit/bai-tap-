# Tái tạo hình kỹ thuật

Cần Python và matplotlib. Chạy `python CONG_CU_TAI_TAO/generate_lad_26.py` từ thư mục gói. Script vẽ lại27hình theo cấu trúc LAD đã rà soát; không tạo XML hay dự án TIA. Đọc thêm `KIEM_THU/network_spec_26.json` cho đặc tả logic. Sửa đặc tả thì phải đối chiếu lại logic vẽ trong script; script không phải trình biên dịch biểu thức tùy ý.
